# Model checkpoint

The pretrained checkpoint is not included in this initial public release.
The intended path used by the synthetic configuration is:

```text
model/checkpoint-step0240000.pth
```

Checkpoint download instructions and a checksum will be added when the model
is released. Files such as `*.pth`, `*.pt`, `*.ckpt`, and `*.safetensors` are
excluded from Git by the repository `.gitignore`.
